# P&L агент — Caspian Sea Support (CSS)

Веб-приложение (Streamlit): загрузка выгрузки 1С ОСВ → P&L по проектам.
Берёт счета 6ххх (доходы) и 7ххх (расходы), раскладывает по проектам,
собирает P&L и сверяет с оборотами 1С (контрольная строка «Разница» = 0).

## Файлы
- `app.py` — интерфейс (главный файл для Streamlit)
- `css_engine.py` — парсер ОСВ + генератор P&L + журнал
- `recalc_native.py` — пересчёт формул (формула + кэш-значение)
- `requirements.txt` — зависимости

## Запуск
Main file path = **app.py**

## Логика
- Доходы 6010 — по проектам; депозит/курсовая/прочие — в блоке «Прочие доходы».
- Прямые затраты 7011 — по проектам (блок на проект), статьи как в 1С.
- Административные 7210/7211/7212 — отдельный блок; налоги с ЗП свёрнуты.
- Низ: финансирование 7300, курсовая расход 7430, прочие 7480.
- Разные написания проектов сводятся в один блок (см. «Журнал сопоставления»).
